# Programming in Java — NPTEL Exam Prep

A simple web-based study companion for revising **NPTEL Programming in Java**. Practise 120 MCQs across 12 weeks, review mistakes, and track your progress.

## Live Website

**[Open Study Hub](https://nptel-java-practice-fawn.vercel.app/)** · [MCQ Practice](https://nptel-java-practice-fawn.vercel.app/practice.html) · [Progress Dashboard](https://nptel-java-practice-fawn.vercel.app/dashboard.html)

## Features

- **120 MCQs across 12 weeks** for structured revision.
- **Practice mode** with immediate answer feedback and explanations.
- **Mock mode** with one question at a time and submit-to-check behaviour.
- **Question review** with search, filters, and review markers.
- **Progress dashboard** showing completion, accuracy, and week-by-week progress.
- **Automatic saving** in the current browser, with no account required.

## Pages

| Page | Description |
| --- | --- |
| [Study Hub](https://nptel-java-practice-fawn.vercel.app/) | Course overview, progress summary, and exam information. |
| [MCQ Practice](https://nptel-java-practice-fawn.vercel.app/practice.html) | Choose a week, practise questions, and review answers. |
| [Dashboard](https://nptel-java-practice-fawn.vercel.app/dashboard.html) | Track saved answers, accuracy, and progress. |

To open a specific week, add `?week=1` through `?week=12` to the practice page URL. For example, [Week 1](https://nptel-java-practice-fawn.vercel.app/practice.html?week=1).

## Progress & Question Bank

Progress is stored in the browser using localStorage. It stays on the current device and browser profile and does not sync across devices. Clearing browser/site data may erase it.

The question bank was prepared from supplied assignment screenshots and study material. Some blurry code snippets were reconstructed for practice, so use official NPTEL/SWAYAM course materials to verify any uncertain answers.

## Tech Stack

- HTML, CSS, and vanilla JavaScript
- Browser localStorage
- Lucide icons
- Deployed on Vercel
